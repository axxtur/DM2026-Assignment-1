# Data Mining Assignment 1: Build the Model from Scratch (Spring 2026)

## Project Overview
This project is for the first assignment of the Spring 2026 Data Mining course at NYCU. The objective is to explore supervised learning models, data exploration, preprocessing, and evaluation techniques by implementing models from scratch and applying them to real-world datasets.

### Key Learning Objectives:
*   **Linear Regression:** Implementing and tuning learning rates for multiple datasets.
*   **Logistic Regression:** Understanding binary classification and the impact of training iterations.
*   **Data Preprocessing:** Handling missing values using K-Nearest Neighbors (KNN) imputation.
*   **Data Exploration:** Analyzing feature correlations and distributions (histograms, boxplots).
*   **Regularization:** Implementing and analyzing the effects of L2 regularization.
